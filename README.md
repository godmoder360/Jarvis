# JARVIS

### Independent Artificial Intelligence Research Project

JARVIS is an independent AI project focused on developing
a locally trained language model with its own neural
network architecture, tokenizer and model weights.

## Current Development

- Custom decoder-only Transformer architecture
- Independently trained BPE tokenizer
- Local neural network training using PyTorch
- Training checkpoint management
- Conversational dataset processing
- Experimental autonomous knowledge collection

## Future Goals

- Advanced natural language understanding
- Improved reasoning and mathematics
- Programming and coding intelligence
- 3D modelling and texture generation
- Universal game development assistance
- Persistent conversational memory
- Autonomous educational research

## Architecture

JARVIS aims to develop its own intelligence without
depending on external hosted AI models.

## Project Status

Currently under active development.
